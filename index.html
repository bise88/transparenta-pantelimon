📐 Cum funcționează monitorizarea Un script Python rulează automat în fiecare luni dimineață pe serverele GitHub. Trage datele bugetare din transparenta.eu (sursă: ANAF/MF) și contractele din SEAP (e-licitatie.ro), aplică 5 algoritmi de detecție a neregulilor, compară cu raportul anterior și publică automat rezultatele pe acest site. Tot codul sursă este public și verificabil.
